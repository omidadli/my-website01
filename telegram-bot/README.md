# 🤖 ربات تلگرام امید عدلی

زیرساخت کامل ربات تلگرام برای **صحت‌سنجی شماره تلفن کاربر**، **تحویل محصولات به مشتری**،
مدیریت سفارش‌ها و اتصال سایت به تلگرام. بدون هیچ وابستگی خارجی (فقط Node.js نسخه ۱۸ به بالا).

---

## ✨ امکانات

| بخش | چه می‌کند |
|---|---|
| 📱 **احراز هویت شماره** | دو روش: اشتراک مستقیم شماره از تلگرام (تاییدشده توسط تلگرام) یا ورود دستی + کد تایید (OTP) داخل چت |
| 🎁 **تحویل محصولات** | کد دسترسی، لینک دانلود، متن یا فایل — بلافاصله پس از تایید سفارش یا خرید از سایت |
| 📦 **سفارش‌ها** | ثبت سفارش با عکس رسید → بررسی ادمین با یک دکمه → تحویل خودکار |
| 🛠 **پنل ادمین** | تایید/رد سفارش، افزودن محصول، پیام همگانی، آمار، دریافت پیام پشتیبانی |
| 🌉 **پل ارتباطی با سایت** | API داخلی برای تحویل خودکار محصول بعد از خرید در سایت (حتی اگر کاربر بعداً تایید کند — در صف می‌ماند) |
| 🔒 **امنیت** | توکن/رمز فقط در `.env`، کنترل دسترسی ادمین، محدودیت نرخ پیام، حالت webhook با secret |

## 🚀 راه‌اندازی در ۵ دقیقه

### ۱) ساخت ربات در تلگرام
1. در تلگرام [@BotFather](https://t.me/BotFather) را باز کنید → `/newbot`
2. یک نام و یک یوزرنیم (مثلاً `omidadli_support_bot`) بدهید
3. **توکن** را کپی کنید (مثلاً `7123456789:AAH...`)

> ⚠️ **توکن را هرگز در چت، گیت‌هاب یا اسکرین‌شات نفرستید.** فقط در فایل `.env` بگذارید.

### ۲) پیکربندی
```bash
cd telegram-bot
cp .env.example .env
# فایل .env را باز کنید و مقادیر را پر کنید:
#   BOT_TOKEN=توکن-از-BotFather
#   ADMIN_TG_IDS=آیدی-عددی-شما
#   WEBHOOK_SECRET=یک-رشته-تصادفی-قوی
```

**آیدی عددی تلگرام خودتان:** به [@userinfobot](https://t.me/userinfobot) پیام دهید.

**WEBHOOK_SECRET:** این دستور را اجرا کنید و خروجی را جایگذاری کنید:
```bash
openssl rand -hex 32
```

### ۳) اجرا
```bash
npm start
```
ربات با **long polling** بالا می‌آید (نیازی به دامنه یا IP عمومی نیست). کافی است در تلگرام به ربات خودتان پیام دهید و `/start` بزنید.

### ۴) تست سلامت
```bash
curl http://localhost:8787/api/health
# {"ok":true,"bot":"omidadli-telegram-bot",...}
```

### ۵) تست منطق (بدون نیاز به تلگرام)
```bash
npm test
```

## 📱 جریان صحت‌سنجی شماره

```
کاربر ── «📱 احراز هویت شماره»
   │
   ├── روش ۱: «اشتراک شماره تلفن من» ──► تلگرام شماره را تاییدشده می‌فرستد ✅ (قوی‌ترین روش)
   │
   └── روش ۲: ورود دستی شماره ──► کد ۶ رقمی در همان چت ──► ورود کد ──► تایید ✅
                                                    (۳ بار تلاش، ۵ دقیقه اعتبار)
```

- شماره به فرمت استاندارد `09xxxxxxxxx` نرمال می‌شود (دقیقاً هم‌قواعد با سایت).
- کاربران تاییدشده با شماره‌شان به حساب سایت لینک می‌شوند.
- محصولاتی که قبل از تایید برای شماره‌ای ثبت شده باشند، **بلافاصله بعد از تایید تحویل داده می‌شوند**.

## 🎁 تحویل محصولات

### روش الف) خرید از سایت (پل خودکار)
سایت بعد از ثبت پرداخت، این درخواست را می‌زند:

```bash
curl -X POST http://localhost:8787/api/deliver \
  -H 'Content-Type: application/json' \
  -H 'X-Bot-Webhook-Secret: YOUR_WEBHOOK_SECRET' \
  -d '{
    "phone": "09123456789",
    "productId": "seo-tool",
    "productName": "ابزار سئو هوشمند",
    "payload": "M4K-7Q2X",
    "type": "code",
    "note": "اعتبار ۳۰ روزه"
  }'
```

- اگر کاربر تلگرامش را تایید کرده باشد → همان لحظه ارسال می‌شود.
- اگر نه → در صف می‌ماند و بعد از تایید شماره، خودکار تحویل داده می‌شود.

انواع `type`: `code` (کد دسترسی) | `link` (لینک) | `text` (متن) | `file` (file_id تلگرام)

### روش ب) سفارش داخل ربات (با رسید پرداخت)
1. کاربر محصول/رسید را می‌فرستد → سفارش `pending` ثبت می‌شود
2. ادمین در `/orders_pending` با دکمه **✅ تایید و تحویل** یا **❌ رد** تصمیم می‌گیرد
3. تایید → تحویل خودکار + اطلاع‌رسانی به کاربر

### روش ج) افزودن دستی محصول (ادمین)
`/addproduct` → عنوان → نوع (کد/لینک/متن/فایل) → محتوا. سپس در تحویل‌ها قابل استفاده است.

## 🛠 دستورهای ادمین

| دستور | کار |
|---|---|
| `/admin` | پنل مدیریت + آمار خلاصه |
| `/orders_pending` | سفارش‌های در انتظار با دکمه تایید/رد |
| `/addproduct` | افزودن محصول جدید |
| `/broadcast` | پیام همگانی به همه کاربران تاییدشده |
| `/stats` | آمار کامل (کاربران، سفارش‌ها، تحویل‌ها) |

## 🌐 پل ارتباطی HTTP (برای اتصال سایت)

| متد | مسیر | هدر | بدنه |
|---|---|---|---|
| GET | `/api/health` | — | — |
| POST | `/api/deliver` | `X-Bot-Webhook-Secret` | `{phone, productId, productName, payload, type, note}` |
| POST | `/api/notify` | `X-Bot-Webhook-Secret` | `{phone, message}` |

نمونه اتصال از سمت سایت (Cloudflare Pages Function) را در `docs/TELEGRAM-BOT-PROMPT.md` ببینید.

## 🔁 حالت‌های اجرا

### Long polling (پیش‌فرض — پیشنهادی برای شروع)
بدون دامنه و گواهی SSL کار می‌کند؛ ربات خودش آپدیت‌ها را می‌کشد.

### Webhook (برای production روی سرور با HTTPS)
```env
BOT_MODE=webhook
PUBLIC_URL=https://bot.example.com
WEBHOOK_SECRET=...
```
آپدیت‌ها روی `POST {PUBLIC_URL}/telegram/{WEBHOOK_SECRET}` می‌آیند (با کنترل secret هدر تلگرام).

## 🚀 استقرار روی سرور (24/7)

**PM2:**
```bash
npm install -g pm2
cd telegram-bot && pm2 start bot.mjs --name tg-bot && pm2 save && pm2 startup
```

**systemd (لینوکس):**
```ini
# /etc/systemd/system/omidadli-bot.service
[Unit]
Description=Omadli Telegram Bot
After=network.target
[Service]
WorkingDirectory=/opt/my-website01/telegram-bot
ExecStart=/usr/bin/node bot.mjs
Restart=always
RestartSec=5
[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now omidadli-bot
```

**Docker:**
```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY . .
CMD ["node", "bot.mjs"]
```


## 🔐 نکات امنیتی
- توکن ربات و `WEBHOOK_SECRET` فقط در `.env` (این فایل git-ignored است).
- اگر توکن لو رفت، در BotFather با `/revoke` توکن را باطل کنید.
- دستورهای ادمین فقط برای `ADMIN_TG_IDS` باز هستند.
- پل HTTP بدون هدر `X-Bot-Webhook-Secret` پاسخ 401 می‌دهد.

| مشکل | راه‌حل |
|---|---|

| محصول تحویل نشد | `GET /api/health` و سپس وضعیت رکورد در `data/deliveries.json` را ببینید (status: failed و lastError) |
