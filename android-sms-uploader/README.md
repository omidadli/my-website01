# OmidPay SMS Uploader (`android-sms-uploader`)

اپلیکیشن اندروید اختصاصی (معادل خودمیزبان `smsUploader.apk` در سرویس Payexa) برای تشخیص لحظه‌ای پیامک‌های واریز بانکی و تأیید خودکار پرداخت‌های کارت‌به‌کارت در وب‌سایت و ربات تلگرام امید عدلی.

## ویژگی‌های امنیتی و فنی
- **فیلتر سخت‌افزاری رمز پویا (OTP) روی گوشی**: پیامک‌های حاوی «رمز پویا»، «رمز دوم»، «کد تأیید» و `OTP` مستقیماً روی خود گوشی مسدود می‌شوند و هرگز از گوشی خارج نمی‌گردند.
- **صف آفلاین مقاوم (`OfflineQueueDb` با SQLite)**: اگر هنگام رسیدن پیامک بانک اینترنت گوشی قطع باشد، پیامک با زمان دقیق دریافت ذخیره شده و به‌محض اتصال مجدد به سرور ارسال می‌گردد.
- **سرویس پایدار پس‌زمینه (`GatewayForegroundService`) + راه‌اندازی خودکار پس از ری‌استارت گوشی (`BootCompletedReceiver`)**.
- **پینگ دوره‌ای سلامت (`POST /api/payment/device/ping`)**: گزارش آنلاین بودن و درصد باتری گوشی به پنل مدیریت سایت.
- **راه‌اندازی ۱-کلیکی**: کپی رشته‌ی اتصال از `پنل مدیریت سایت -> درگاه کارت‌به‌کارت خودکار -> اپلیکیشن اندروید` و زدن دکمه «الصاق خودکار از کلیپ‌بورد».

## نحوه دریافت فایل نصبی `APK`
1. **روش خودکار (پیشنهادی — بدون نیاز به نصب Android Studio)**:
   - ورک‌فلوی `.github/workflows/build-android-apk.yml` با هر تغییر در `android-sms-uploader/` یا به‌صورت دستی از تب **Actions -> Build Android SMS Uploader APK -> Run workflow** در GitHub اجرا می‌شود و فایل نصبی `omidpay-sms-uploader-debug.apk` را در بخش **Artifacts** تحویل می‌دهد.
2. **روش کامپایل محلی در Android Studio**:
   - پوشه `android-sms-uploader` را در Android Studio باز کنید و گزینه `Build -> Build Bundle(s) / APK(s) -> Build APK(s)` را بزنید.
